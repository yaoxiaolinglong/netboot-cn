## 五、这张表里没有的

| **Windows 全系** | 必须自备 ISO，见 [Windows安装.md](Windows安装.md) |

| **UOS 统信** | 同上，需商业授权 |
| **openKylin 麒麟** | 同上 |
| **Ubuntu Kylin 优麒麟** | 同上 |
| **Arch 官方 ISO** | 列表里只有 Zen 安装器，原味 Arch 需自备 |
| **FreeBSD 以外的小众 BSD** | 需自备 |

国产发行版不在 netboot.xyz 收录范围，这是上游的选择，不是本项目的取舍。
