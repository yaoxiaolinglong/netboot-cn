# 常见问题

## 启动阶段

### 开机看不到 U 盘

1. **没关 Secure Boot**。进 BIOS 关掉，本项目的 EFI 没签名
2. **选了 Legacy/CSM 那一项**。必须选带 `UEFI:` 前缀的
3. **U 盘没写好**。重新跑 `sudo ./install-usb.sh /dev/sdX`
4. **固件太老**。2015 年前的机器可能只支持 Legacy，本项目不做 Legacy 引导

### 黑屏，没有任何画面

gfxterm 在某些老显卡上起不来。临时办法：菜单其实在跑，只是没显示——按方向键和回车盲选也能用。

要根治，把 `src/grub.cfg` 里这段注释掉，重新构建：

```grub
# if loadfont /boot/grub/fonts/cn.pf2 ; then
#   set gfxmode=1024x768,800x600,auto
#   terminal_output gfxterm
# fi
```

会退回文本模式菜单（一样能选，只是难看）。

### 中文显示成方块或者空白

字库没覆盖到那个字。检查：

```bash
./build.sh    # 会自动重新扫描字符集
```

如果是自己改过 `grub.cfg` 后没重新构建，配置根本没生效——**配置是内嵌在 EFI 里的**。

### 菜单一闪而过直接启动硬盘

`timeout` 太短，或者键盘没接上。改 `src/grub.cfg`：

```grub
set timeout=60
```

## 安装阶段

### 选了 ①② 之后长时间没反应

GRUB 在下载 initrd（约 39 MB）。网速 1 MB/s 的话要 40 秒。**耐心等 2 分钟**，屏幕不动是正常的——GRUB 的 http 模块没有进度条。

超过 3 分钟还是黑的：

1. 检查网线是否插好、路由器有没有给 IP
2. 换 ②（中科大源）试试
3. 两个都不行，说明 GRUB 的 http 模块和你的网卡/网络环境不兼容，改用 ⑥ netboot.xyz

### ④ CentOS Stream 特别慢

它的 initrd 有 77 MB，是 ①② 的两倍。首次加载慢是正常的。

### 无线网卡能用吗

分两种情况：

**已经跑过 `./scripts/fetch-images.sh` 的盘（推荐）**

①②③ 全程无线可用——内核在 U 盘里（引导不联网），固件注入进了 initrd（安装器能连 WiFi）。

**没跑过的盘**

引导阶段必须插网线，因为 GRUB 的无线驱动几乎为零，只能靠 `net_bootp` 走有线。装完进系统后 WiFi 正常。

### 注入固件后 WiFi 还是不认

说明你的网卡不在注入的三个包（Intel / Realtek / 联发科）里。

1. 查网卡型号：进 Windows 设备管理器，或 Linux 上 `lspci | grep -i network`
2. 确认它属于哪个固件包（Debian 的 `non-free-firmware` 仓库里找）
3. 加到 `scripts/fetch-images.sh` 顶部的 `FW_PACKAGES` 数组
4. 重新跑 `./scripts/fetch-images.sh` 和 `./install-usb.sh`

常见包名：`firmware-atheros` `firmware-brcm80211` `firmware-misc-nonfree`

### 装到一半断网了

Debian 的网络安装必须全程联网（软件包是现下的）。断了就退回上一步重试，或者重启整个安装。

想避免：用有线，或者选「只装基础系统」把联网需求降到最低。

## 系统选择

### 我这台机器适合装什么

按硬件分：

| 硬件 | 推荐 |
|---|---|
| 4 GB 内存以下 / 双核老 U | Alpine、Tiny Core、Linux Lite、Q4OS |
| 4-8 GB / 四核 | Debian + XFCE、Linux Mint XFCE、MX Linux |
| 8 GB 以上 / 六核以上 | 随便挑，Debian、Fedora、CachyOS 都行 |

**低配机器别选 GNOME 或完整 KDE**，光桌面就吃掉 1.5 GB 内存。

Debian 安装时在「软件选择」里取消 GNOME，勾 XFCE。

### 为什么没有 Deepin / UOS / 麒麟

netboot.xyz 不收录国产发行版。要装只能下载 ISO，用 Ventoy 或 dd 写盘。

## 技术细节

### 镜像 IP 为什么要硬编码

GRUB **没有 DNS 模块**（`/usr/lib/grub/x86_64-efi` 里没有 `dns.mod`），只能填 IP。

当前用的：
- 清华源 `101.6.15.130`
- 中科大 `202.141.160.110`

IP 变了菜单就失效，改 `src/grub.cfg` 里对应的地址重新构建。

查询当前 IP：

```bash
getent ahostsv4 mirrors.tuna.tsinghua.edu.cn
getent ahostsv4 mirrors.ustc.edu.cn
```

### 为什么只有 4 个系统能直连

GRUB 的 http 模块要一次性把 initrd 读进内存。实测：

- Debian 39 MB ✅
- Alpine 27 MB ✅
- CentOS Stream 77 MB ✅（边界）
- Fedora 252 MB ❌
- Rocky/Alma 218 MB ❌
- openSUSE 227 MB ❌

超过 100 MB 基本拉不动。这些走 netboot.xyz，iPXE 处理大文件没问题。

### 能不能加 Legacy BIOS 支持

技术上可以（`grub-mkstandalone -O i386-pc` + 写引导扇区），但：

- 需要额外的 i386-pc 模块包
- 现代机器 99% 是 UEFI
- 维护成本翻倍

暂不做。有需求可以提 issue。

### 能不能让 netboot.xyz 也显示中文

不能。看源码：

```c
/* iPXE src/core/console.c */
int putchar ( int character ) {
        console->putchar ( character );
}
```

逐字节处理，全树没有 UTF-8 解码。要中文必须重写渲染层 + 造几千字库 + 重编译，而且 netboot.xyz 的菜单是服务器下发的，本地改了也不生效。

本项目的中文来自 GRUB 层，这是唯一可行路径。

## 还是搞不定

把这三个信息发出来：

1. 机器型号
2. 卡在哪一步（菜单第几项、屏幕上最后一行字）
3. 手机拍的屏幕照片

有这三点基本都能定位。
